fix: satisfy script-src CSP — no inline scripts or onload handlers

Lighthouse against production reported two CSP violations that the local
server could not catch, because it sends no Content-Security-Policy:

- the inline no-flash theme script was blocked by script-src
- the font stylesheet's onload="this.media='all'" handler was blocked

Best Practices was sitting at 92 as a result.

Both are now CSP-clean without weakening the policy:

- the theme script moved into assets/js/main.js, which is already loaded
  synchronously in <head>, so it still runs before first paint
- the font link keeps media="print" but is switched to media="all" by an
  addEventListener in main.js instead of an inline attribute

script-src is unchanged and still has no 'unsafe-inline'.
